Charts Without Libraries

Every figure on this page is hand-built inline SVG — charts and diagrams alike. No charting library, no diagramming engine, no CDN, no build step. This is what's actually available when you want a picture instead of a paragraph.

Sample data. Every number below is synthetic, invented to exercise the chart forms. Nothing here reflects real volumes.

When it isn't a chart

job: one headline

A single number with a trend behind it beats a chart of one series. Sparkline for shape, delta for direction, and the number itself stays the loudest thing in the tile.

Change over time

job: trend, two series

Move across the plot — a crosshair tracks the nearest day and reads both series at once. This is the interaction the terminal can never give you.

Composition

job: parts of a whole

Stacked bars carry both total and mix. Two of these series fall under 3:1 against the light surface, so colour alone can't be load-bearing: segments deep enough to hold a number get one, and the rest are covered by the table beneath — which doubles as the screen-reader path.

Rank

job: magnitude, ordered

One series, sorted, labelled at the end of each bar. No legend needed — the title names the series.

Density

job: magnitude across two dimensions

A sequential ramp — one hue, light to dark. Never a rainbow: the reader has to be able to order the colours without a decoder ring.

Process

hand-authored SVG · flowchart

Branching logic reads as a diagram once decisions become diamonds and outcomes become pills — the shape already tells you what kind of step it is, before you've read the label. Drawn as SVG, every box and arrow is markup styled with the same tokens as the charts above.

Protocol

hand-authored SVG · sequence

Sequence diagrams answer "who calls whom, in what order, and who is waiting" — a question prose is genuinely bad at. Drawn as SVG, the lifelines and the branch boundary are just shapes, styled with the same tokens as everything else on the page.

Mechanism

hand-authored SVG

When you're comparing two options, draw the difference rather than restating the list. Hand-authored SVG earns its keep exactly here — Mermaid can't lay out a deliberate side-by-side comparison.

How this page is built

No libraries, by force

The CSP blocks external scripts, so D3, Chart.js and friends are unavailable. Charts are SVG generated by ~120 lines of inline JavaScript from literal data arrays.

No Mermaid, on purpose

It renders natively inside an artifact, but a fenced mermaid block doesn't survive a file export — it shows up as raw, unrendered text once the page is saved and opened outside claude.ai — and it draws once with a fixed theme, so its colours can't follow the viewer's light/dark setting. Both diagrams above are hand-authored SVG instead, for exactly those two reasons.

Colour is validated, not chosen

The categorical palette was run through a contrast and colour-blindness validator in both themes before any chart code was written. Adjacent-hue separation clears the CVD threshold in light and dark.

Both themes are designed

Dark isn't an inversion — it's a second set of steps chosen against the dark surface. Every colour is a token, so the two swap in one place.
